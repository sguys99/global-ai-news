## 측정하지 못한 항목과 이유

1. **GoatCounter 경로 상위 10개 목록·리퍼러·국가·브라우저** — 목록형 데이터는 GoatCounter API 토큰이 필요하다. `.env.local`에 GOATCOUNTER 관련 변수가 없다(변수명만 확인). 지금은 방문 11회·경로 5개라 위 표가 사실상 전체 목록이다. 국가 분포(Phase 8-1 비교 대상)는 대시보드(https://sguys99.goatcounter.com)에서 직접 읽어야 한다.
2. **GoatCounter 일 방문 정확값** — 공개 counter의 날짜 범위 질의는 되지만 4시간 캐시 때문에 날짜별 값이 서로 어긋난다. 대시보드에서 읽는다. 누적 11회에는 운영자 본인 확인 방문이 섞였을 가능성이 크다(count.js는 localhost만 거름) — 대시보드에서 본인 방문 제외 설정 여부도 확인 필요.
3. **Search Console 노출·클릭·색인 페이지 수** — 2026-11-03 등록, 데이터 없음. 약 2026-11-17에 기록.
4. **운영 회차의 단계별(가공만) 출력 토큰** — `collection_runs`는 선별·가공·재보도 합계만 저장한다. 가공 단독 값은 `--no-save` 스냅숏(10-29, 10-31) 기준 추정이다. 단계별 기준선이 필요하면 Phase 1-4의 `--no-save` 실행에서 개편 전/후를 같이 잰다.

## 참고 (계획서에 반영 검토)

- **비용 기준선 주의:** 14회 평균 $0.031은 개편 전 4회 호출 회차(평균 $0.026) 11개와 개편 후 회차 3개가 섞인 값이다. 11-01 배포 이후 현재 파이프라인(6회 호출: 선별·가공 4·재보도, 입력 약 69k 토큰)은 **회차당 약 $0.053**다. 계획서의 "평균 $0.031 → 약 $0.04" 예상은 **약 $0.053 → $0.063** 정도로 고쳐야 하며, 상한 $0.1 대비 여유는 약 $0.04다.
- 가공 출력은 기사당 약 180토큰으로 예산 350의 절반 정도만 쓴다. 영어 제목·요약(약 +80~90토큰)을 더해도 약 270이다. 1-2의 550 상향은 여유를 둔 값으로 충분하다.
- 계획서 표의 "1,232 / 31% (380건)"은 한글 원제 기사 수(380)와 같다. 소스 기준으로는 381건(GeekNews 영문 제목 1건 포함)이다.
- 140회 중 138회가 `partial`이다(소스 일부 실패 시). 성공률 KPI는 100%로 잡힌다.
