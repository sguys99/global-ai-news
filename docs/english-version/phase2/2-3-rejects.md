- **연도 질문에 대한 답:** 기각된 연도 12건(2026 ×7, 2025 ×4, 2024 ×1) 중 원문 발췌 밖에 근거가 있는 것은 없다. 2026 7건은 같은 묶음 다른 기사에서 온 행사명, 나머지 5건은 상대 표현("올해·내년·this year")을 모델이 잘못 바꾼 것이다. 모델 입력에 기사 날짜가 없으니(가공·백필 모두 `[형식]·[출처]·[제목]·[본문]`) 모델은 연도를 알 수 없다. english.md는 이미 "Do not add … years that are not in the input"이라고 한다. 날짜를 근거에 넣으면(아래) 2026 7건은 통과하지만, 오히려 "내년 → 올해 연도" 같은 오류도 통과하게 된다.

## 검사기 수정 제안 (적용하지 않음)

`scripts/lib/englishCheck.ts`는 일일 가공의 영어 검사와 한국어 숫자 경고에 함께 쓰인다. 고치면 다음 날 수집부터 바로 적용된다. 그래서 근거 쪽을 넓히거나 수량이 아닌 토큰만 빼는 좁은 수정만 제안한다. 우선순위 순:

1. **수량이 아닌 용어 토큰 제외 (권장).** 출력·근거 모두 숫자를 뽑기 전에 `\bCO2\b`·`CO₂`·`\b[234]D\b`를 숫자 없는 토큰으로 바꾼다. 근거 쪽은 NFKC 정규화로 아래첨자를 ASCII로 바꾼다(`CO₂` → `CO2`). `H100`·`B200`·`GPT-4` 같은 모델명은 건드리지 않는다.
   - 통과해야 함: `CO2 batteries` ← "carbon dioxide gas" / `8.5 times more CO2` ← 원제 `CO₂를 8.5배` / `3D models` ← "printable model"
   - 계속 막아야 함: `3 models` ← "printable model" / `H200` ← "H100" / `2 batteries` ← "carbon dioxide"
2. **범위의 단위 물려받기 (권장).** 출력에서 `숫자 [–-~] 금액(scale·만억조 포함)` 모양이면 앞 숫자에 뒤 금액의 단위·통화를 붙여 값으로 비교한다.
   - 통과: `$1–2 billion` ← `10억~20억달러` / `$1-2 billion` ← "between $1 billion and $2 billion"
   - 막음: `$1–2 billion` ← `1억~2억달러`(지금도 `2 billion`으로 걸림, 유지) / `$10–20 billion` ← `10억~20억달러`
3. **영어 수 단어 합성 (선택, 근거 쪽만).** `two hundred (and) fifty` = 250, `twenty-five` = 25, `three hundred` = 300을 근거 숫자에 더한다. 지금 수 단어 철학(근거 쪽만 넉넉하게)과 같다.
   - 통과: `250th anniversary` ← "Two hundred and fifty years" / `25 people` ← "twenty-five people"
   - 막음: `205th` ← "Two hundred and fifty"
4. **반올림 허용 (선택, 보류 쪽).** 출력 숫자가 근거 값을 출력 자릿수로 반올림한 값과 같고 상대 오차가 1% 이내일 때만 통과시킨다. 금액이면 출력 단위로 나눈 값으로 비교한다. 10배 단위 오류는 그대로 막힌다. 다만 0-3에서 반올림을 "엄밀히 규칙 위반"으로 본 판단과 부딪친다. 1,255건 중 2건뿐이라 지금은 보류를 권한다.
   - 통과: `35%` ← `35.3%` / `1.41 trillion won`·`1.4 trillion won` ← `1조4131억원`
   - 막음: `36%` ← `35.3%` / `1 billion` ← `1.4 billion`(28%) / `1.41 billion won` ← `1조4131억원`(1000배)

- **고치지 않을 것:**
  - **통화 추정(#1188).** `500M` → `$500 million`을 통과시키려면 통화 근거 없이 달러를 허용해야 한다. 그러면 통화 바꿔치기 검사가 약해진다.
  - **연도를 근거에 넣는 것(기사 날짜의 연도).** 2026 7건은 풀리지만, "내년 → 올해 연도" 오류(#1117·#754 유형)가 다음에는 2026으로 나와 통과한다. 연도는 지금처럼 막고, 필요하면 english.md에 "Keep relative time words ('this year', 'next year') as written; never turn them into a year" 한 줄을 더하는 쪽이 낫다(가공·백필 공용, 비용 0).
