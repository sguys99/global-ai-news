### 두 숫자가 다른 이유 (2-3 메모)

DB 보유율과 "1 − notes 기각률"은 서로 다른 것을 센다. 분모·출처·시점이 모두 다르다.

| 차이    | 수집 경로 커버리지·기각률                    | DB 보유율                                          |
| ------- | -------------------------------------------- | -------------------------------------------------- |
| 분모    | 영어 회차의 게재분 64건(11-05~)              | 영어판 시작(06-07) 이후 전체 게재 1,319건          |
| 시점    | 회차 당시 검사 결과                          | 지금 DB(백필·`--ids` 재시도·`--fixes` 반영)        |
| 빠진 것 | 백필 기각 32건·재기각 6건(notes를 쓰지 않음) | 없음 — 영어가 없으면 이유와 상관없이 빈자리로 센다 |

빈자리 대조(2026-11-07, kpi 출력과 같다):

```
게재 1,319 − 영어 1,303 = 영어 없음 16건
  = 회차 기각 2   (#1368 11-05 호 · #1396 11-06 호 — notes 숫자 기각)
  + notes 밖 14   (백필 1,255건 중 영어 없음: 재기각 6 #155·221·301·485·1188·1255
                    + 본문 없음 8 #22·23·25·27·471·670·703·757 — 2-3 기록)
백필 분해: 1,255 = 첫 실행 영어 1,223 + 재시도로 채움 18 + 남은 14
          (첫 실행 기각 32 = 재시도 성공 18 + 재기각 6 + 재시도 안 함 8. 재시도 28건 중 4건은 기존 영어 덮어쓰기)
지역: 한국 매체 1(#301, 재기각) · 해외 15
```

- 수집 경로에서 기각된 기사는 `--ids`로 백필 재시도를 하면 DB 보유율만 오르고 notes 기각은 그대로다. 이 경우 `englishGap`은 notes 밖 몫을 0으로 자른다.
- 기각된 영어 원문은 백필은 보고서 아티팩트(30일)에, 일일 수집은 **어디에도** 남지 않는다(아래 "오탐 검토").

## 후속 과제

1. **(권장, 작음) 일일 수집의 영어 기각 상세를 남긴다.** `영어 기각` notes 줄 뒤에 기사 id와 검사 상세를 붙이거나(예: `영어 기각 1건(한글 0·숫자 1·길이 0: #1368 278 trillion)`), 최소한 Actions 로그에 `EN ✗` 줄을 찍는다. 지금은 기각 2건의 오탐 여부를 판정할 수 없다. notes 형식을 바꾸면 `parseEnglishNotes`가 앞부분만 읽으므로 호환된다(테스트로 확인 필요). 그 뒤 2주차 리뷰에서 "숫자 기각 중 오탐 ≤ 1/3" 목표를 정한다.
2. **용어집에 음차 변형을 더한다:** `미토스 → Mythos`(#1412). 같은 계열 변형(미소스/미토스, 그록/그로크처럼)을 한국 매체 최근 30일 표기로 한 번 훑는다. #1412 영어는 `--fixes-only` 수정 목록으로 고친다.
3. **#1400 한국어 숫자 수정:** `summary_ko` "594억 파라미터" → "5,940억 파라미터". 다음 수정 목록 실행에 넣는다(`ko-fixes-p7` 방식).
4. **(Phase 9 후보) 논문 `summary_ko` 길이:** 논문 가이드("문제 → 방법 → 결과를 한 줄씩")에 글자 상한(예: 200자)을 둘지 정한다. 영어를 같은 호출에 넣은 뒤로 한국어 요약 전반이 길어졌다(뉴스 107 → 131자, 논문 142 → 207자). 화면(상세·색인 카드) 줄 수를 보고 판단한다.
5. **(관찰) 2주차 리뷰(11-19 전후):** `npm run kpi -- 14` 영어판 절의 목표 표·회차 줄을 옮긴다. 35건에 가까운 회차가 생기면 비용 환산($0.069)을 실측으로 바꾼다. Phase 7 규칙 뒤 호 몇 개를 7-6 기준으로 표본 통독해 사소·오류 비율 추세를 본다.
6. **(관찰) 한국 매체 표본이 얇다:** 3일 6건이라 원화 금액·한국 인명 규칙은 거의 시험되지 않았다. Phase 9 "Korea Desk 공급"과 함께 2주차에 다시 본다.
